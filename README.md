# SyntecxHub Rule-Based Expert System

## Project Overview

This project implements a Rule-Based Expert System using Forward Chaining in Python. The system takes user-provided symptoms as input, applies predefined IF-THEN rules, and derives conclusions automatically.

## Features

* Rule Engine
* Knowledge Base
* Forward Chaining
* Multi-Step Inference
* Inference Logging
* User-Friendly Console Interface

## Sample Rules

* IF fever AND cough THEN flu
* IF flu AND body_pain THEN doctor_visit
* IF sore_throat AND cough THEN cold
* IF cold AND fever THEN infection
* IF infection THEN medical_checkup

## Technologies Used

* Python 3
* Artificial Intelligence Concepts
* Rule-Based Systems
